# 90s Period Asset Archives & References

Always download assets locally into `assets/` (e.g. via `fetch_asset` / `rwk fetch-asset`) and never hotlink.

## Real Period Assets
- **GifCities (Internet Archive's GeoCities GIF Search):** https://gifcities.org/
  - Great search terms: `under construction`, `divider`, `glitter`, `welcome`, `email me`, `sign my guestbook`, `netscape now`, `dancing`, `rainbow`, `bar`, `flame`, `spinning`.
  - Accessible directly via `search_gifs` / `rwk search-gifs`.
- **88x31 Web Buttons:**
  - https://cyber.dabamos.de/88x31/ (searchable via `search_buttons` / `rwk search-buttons`)
  - https://github.com/transicle/88x31 (86,000+ buttons)
  - http://textfiles.com/underconstruction/88x31/
- **Tileable Backgrounds:**
  - Pixel Moondust archive (2,100+ classic tiles, linked from https://hedorah.neocities.org/)
  - Or generate custom seamless starfields via `generate_starfield` / `rwk generate-starfield`.
